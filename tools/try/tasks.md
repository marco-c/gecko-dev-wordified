#
Task
Generation
Many
selectors
(
including
chooser
coverage
and
fuzzy
)
source
their
available
tasks
directly
from
the
{
ref
}
taskgraph
<
taskcluster
-
task
-
graph
-
generation
>
module
by
building
the
taskgraph
locally
.
This
means
that
the
list
of
available
tasks
will
never
be
stale
.
While
this
is
very
powerful
it
comes
with
a
large
enough
performance
cost
to
get
annoying
(
around
twenty
seconds
)
.
The
result
of
the
taskgraph
generation
will
be
cached
so
this
penalty
will
only
be
incurred
whenever
a
file
in
the
/
taskcluster
directory
is
modified
.
Unfortunately
this
directory
changes
